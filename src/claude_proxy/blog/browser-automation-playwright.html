کلاد فقط کد نمی‌نویسد؛ اگر Playwright را به آن وصل کنید، یک مرورگر واقعی را باز می‌کند، کلیک می‌کند، تایپ می‌کند، صفحه را می‌خواند و اسکرین‌شات می‌گیرد. شما به فارسی می‌گویید چه می‌خواهید و کلاد خودش در مرورگر انجامش می‌دهد. برای راه انداختنش لازم نیست دستوری بلد باشید؛ کلاد خودش نصبش می‌کند.

نصب

کلاد در همان Chrome که الان باز است کار می‌کند، با همان حساب‌هایی که در آن‌ها وارد شده‌اید.

  1. اگر هنوز کلاد را نصب نکرده‌اید، اول راهنمای نصب کلاد را دنبال کنید.
  2. ترمینال را باز کنید: در ویندوز در منوی Start عبارت PowerShell را جست‌وجو و بازش کنید؛ در مک Cmd+Space را بزنید، Terminal را بنویسید و Enter بزنید.
  3. gclaude (جی کلاد) را اجرا کنید، بعد این پیام را کپی پیست کنید و Enter بزنید: 
    Set up Playwright so you can work in the Chrome I already have open:
1. Check my operating system, and check with node -v that Node.js 18 or newer is installed. If it isn't, install it (Windows: winget install OpenJS.NodeJS.LTS, macOS: brew install node).
2. If playwright is in gclaude mcp list, remove it with gclaude mcp remove playwright -s user.
3. Add it with gclaude mcp add playwright -s user -- npx @playwright/mcp@latest --extension. On Windows, use cmd /c npx instead of npx.
4. Open this page in Chrome so I can install the Playwright MCP Bridge extension: https://chromewebstore.google.com/search/Playwright%20MCP%20Bridge
5. Finally, briefly tell me in Persian what you did and what is left for me to do.
  4. اگر کلاد برای اجرای دستوری اجازه خواست، تأیید کنید.
  5. در صفحه‌ای که در Chrome باز شد، افزونه Playwright MCP Bridge را با دکمه Add to Chrome نصب کنید.
  6. gclaude را ببندید و دوباره باز کنید. برای امتحان بنویسید: «سایت rahkar.pro را در مرورگر باز کن و بگو در صفحه اولش چه نوشته.» بار اول افزونه در Chrome می‌پرسد کدام تب را در اختیار کلاد بگذارد؛ تب را انتخاب و تأیید کنید.

کلاد در این مرورگر هر کاری که شما می‌توانید بکنید، می‌تواند بکند. پس فقط برای کارهایی از آن استفاده کنید که واقعاً به حساب‌های شما نیاز دارند.

نصب دستی (برای کسانی که با ترمینال راحت‌اند)

  1. Node.js نسخه ۱۸ یا بالاتر را نصب کنید. برای بررسی، در ترمینال node -v را بزنید.
  2. افزونه Playwright MCP Bridge را از Chrome Web Store در Chrome نصب کنید.
  3. اگر Playwright را قبلاً اضافه کرده‌اید، اول پاکش کنید: 
    gclaude mcp remove playwright -s user
  4. Playwright را با --extension به کلاد اضافه کنید: 
    gclaude mcp add playwright -s user -- npx @playwright/mcp@latest --extension
    با -s user در همه پوشه‌ها در دسترس است، نه فقط پوشه فعلی. در ویندوز اگر وصل نشد، npx را به cmd /c npx تغییر دهید.
  5. gclaude را اجرا کنید، /mcp را بزنید و ببینید playwright وصل شده باشد.

مرورگر جدا به‌جای Chrome خودتان

اگر نمی‌خواهید کلاد به حساب‌هایتان دسترسی داشته باشد، می‌تواند یک مرورگر جدا و خالی باز کند که در هیچ سایتی وارد نشده‌اید. gclaude را اجرا کنید و این پیام را کپی پیست کنید:

Set up Playwright so you can control a separate web browser for me:
1. Check my operating system, and check with node -v that Node.js 18 or newer is installed. If it isn't, install it (Windows: winget install OpenJS.NodeJS.LTS, macOS: brew install node).
2. If playwright is in gclaude mcp list, remove it with gclaude mcp remove playwright -s user.
3. Add it with gclaude mcp add playwright -s user -- npx @playwright/mcp@latest. On Windows, use cmd /c npx instead of npx.
4. Run npx playwright install chromium so the browser is downloaded.
5. Finally, briefly tell me in Persian what you did and what is left for me to do.

بعد gclaude را ببندید و دوباره باز کنید. اگر دستی نصب می‌کنید، همان مراحل بالا را بدون افزونه و بدون --extension انجام دهید و یک بار npx playwright install chromium را اجرا کنید.

با کلاد و مرورگر چه کارهایی می‌شود کرد؟

کارهای تکراری و جمع‌آوری داده از وب

  • پر کردن فرم‌های تکراری: ثبت ده‌ها مورد در یک پنل مدیریت سایت یا فرم‌های ثبت نام، از روی یک فایل اکسل.
  • جمع‌آوری داده از وب: قیمت محصولات، آگهی‌های شغلی یا فهرست مقاله‌ها، مرتب در یک فایل اکسل.
  • مقایسه سایت با فایل: «همه صفحه‌های محصول را باز کن و قیمت و توضیحات را با فایل اکسل مقایسه کن؛ هر جا فرق دارد فهرست کن.» برای فروشگاه‌ها بعد از هر به‌روزرسانی قیمت.

گزارش و راهنما

  • اسکرین‌شات و PDF: «از این ۲۰ صفحه سایت در اندازه موبایل و کامپیوتر اسکرین‌شات بگیر و یک PDF گزارش بساز.» برای نشان دادن کار به کارفرما یا نگه داشتن سابقه.
  • نوشتن راهنما: «مراحل ساخت حساب در پنل مدیریت را انجام بده و از هر مرحله اسکرین‌شات بگیر، بعد یک راهنمای فارسی قدم‌به‌قدم بنویس.» برای راهنمای مشتری‌ها و آشنا کردن همکاران تازه.

سه نمونه که می‌توانید همین الان امتحان کنید

  • «یک فروشگاه اینترنتی را باز کن و نام و قیمت ۱۰ لپ‌تاپ اول را در یک فایل اکسل بریز.»
  • «این پنج لینک آگهی را باز کن و عنوان، قیمت و شماره تماس هر کدام را در یک جدول برایم بنویس.»
  • «سایت فروشگاهم را در اندازه موبایل باز کن، یک محصول را به سبد خرید اضافه کن و هر جا چیزی خراب یا عجیب بود با اسکرین‌شات بگو.»

برای برنامه‌نویس‌ها: تست، رفع باگ و SEO

  • تست سایت خودتان: «سایت من روی localhost:3000 را باز کن، مسیر ثبت نام و پرداخت را از اول تا آخر طی کن و هر خطا را با اسکرین‌شات گزارش بده.»
  • بازسازی باگ: «این باگ را که کاربر گزارش داده بازسازی کن: وارد شو، سبد خرید را پر کن و دکمه پرداخت را بزن؛ خطای کنسول و درخواست‌های شبکه را بیاور و علتش را در کد پیدا کن.» از مرورگر مستقیم به رفع باگ در کد.
  • نوشتن تست خودکار: «از کاری که الان کردی یک تست Playwright بنویس و اجرایش کن» تا در CI هر بار اجرا شود.
  • تست در چند اندازه صفحه: «فرم ثبت نام را در سایز موبایل، تبلت و دسکتاپ امتحان کن و هر جا دکمه یا متن از صفحه بیرون زده گزارش بده.»
  • مقایسه ظاهر دو نسخه: «صفحه اصلی سایتم را با نسخه staging مقایسه کن و هر تفاوت ظاهری را با اسکرین‌شات نشان بده.» برای پیدا کردن استایل‌های خراب قبل از انتشار.
  • بررسی SEO و دسترس‌پذیری: «سایتم را باز کن و بررسی کن کدام صفحه‌ها title، description یا alt عکس ندارند و لینک شکسته دارند؛ گزارش بده و درستشان کن.»

چند نکته ایمنی

  • با این نصب، کلاد در Chrome خودتان و با حساب‌های شما کار می‌کند. برای کارهایی که به حساب‌هایتان نیازی ندارند، مثل جمع کردن داده از سایت‌های عمومی، از «مرورگر جدا به‌جای Chrome خودتان» استفاده کنید.
  • رمز عبور و اطلاعات کارت را به کلاد ندهید؛ این قدم‌ها را خودتان انجام دهید.
  • قوانین سایت‌هایی را که از آن‌ها داده جمع می‌کنید رعایت کنید و درخواست‌ها را پشت سر هم و زیاد نفرستید.

کدام بسته برای کدام کار

کار با مرورگر توکن بیشتری از کدنویسی معمولی مصرف می‌کند، چون کلاد هر صفحه‌ای را که باز می‌کند می‌خواند. برای کارهای سنگین‌تر بسته استاندارد را انتخاب کنید.

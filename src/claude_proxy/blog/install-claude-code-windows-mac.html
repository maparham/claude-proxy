Claude Code نسخه ترمینالی کلاد (Claude یا کلود) است که روی کامپیوتر خودتان اجرا می‌شود. نصب معمولی آن به اکانت Anthropic و اشتراک Claude Pro نیاز دارد که از ایران در دسترس نیست. با بسته‌های راهکار هوش برتر همه این کارها با یک دستور انجام می‌شود.

پیش از شروع

  • یک بسته کلاد بخرید و وارد داشبورد شوید.
  • در ویندوز، PowerShell و در مک و لینوکس، Terminal را باز کنید. دسترسی ادمین لازم نیست.

نصب روی مک و لینوکس

این دستور را در Terminal اجرا کنید:

curl -fsSL https://dash.rahkar.pro/install | sh

نصب روی ویندوز

این دستور را در PowerShell اجرا کنید:

irm https://dash.rahkar.pro/install.ps1 | iex

وصل کردن کامپیوتر

  1. دستور نصب، اگر Claude Code روی کامپیوترتان نباشد، خودش آن را نصب می‌کند.
  2. بعد یک صفحه در مرورگر باز می‌شود و یک کد نشان می‌دهد. بررسی کنید ترمینال هم همان کد را نشان بدهد و تأیید کنید.
  3. به ترمینال برگردید؛ راه اندازی خودش تمام می‌شود.

اجرای کلاد

به پوشه پروژه بروید و gclaude را اجرا کنید. حالا کلاد با مدل‌های Opus و Sonnet آماده کار است. در VS Code هم همین دستور را در ترمینال خود VS Code اجرا کنید.

چند نکته

  • مصرف بسته و زمان باقی‌مانده را در داشبورد ببینید.
  • برای وصل کردن کامپیوتر دوم، همین دستور را روی آن هم اجرا کنید.
  • اگر مشکلی پیش آمد، از دکمه پشتیبانی پایین صفحه در تلگرام یا واتس‌اپ بپرسید.

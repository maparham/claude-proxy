Claude Code نسخه ترمینالی کلاد (Claude، کلود یا کلاود) است که روی کامپیوتر خودتان اجرا می‌شود. نصب معمولی آن به اکانت Anthropic و اشتراک Claude Pro نیاز دارد که از ایران در دسترس نیست. با بسته‌های راهکار هوش برتر همه این کارها با یک دستور انجام می‌شود، و همان بسته را در Claude Desktop هم می‌توانید به کار ببرید.

پیش از شروع

  • یک بسته کلاد بخرید و وارد داشبورد شوید.
  • در ویندوز، PowerShell و در مک و لینوکس، Terminal را باز کنید. دسترسی ادمین لازم نیست.

نصب روی مک و لینوکس

این دستور را در Terminal اجرا کنید:

curl -fsSL https://dash.rahkar.pro/install | sh

نصب روی ویندوز

ساده‌ترین راه، فایل نصب است:

  1. فایل نصب را دانلود کنید: https://dash.rahkar.pro/install.cmd
  2. فایل دانلودشده (claude-gateway-setup.cmd) را باز کنید. اگر Windows پیام «Windows protected your PC» نشان داد، روی «More info» و بعد «Run anyway» بزنید.

یا این دستور را در PowerShell اجرا کنید:

irm https://dash.rahkar.pro/install.ps1 | iex

وصل کردن کامپیوتر

  1. دستور نصب، اگر Claude Code روی کامپیوترتان نباشد، خودش آن را نصب می‌کند.
  2. بعد یک صفحه در مرورگر باز می‌شود و یک کد نشان می‌دهد. بررسی کنید ترمینال هم همان کد را نشان بدهد و تأیید کنید.
  3. به ترمینال برگردید؛ راه اندازی خودش تمام می‌شود.

اجرای کلاد

به پوشه پروژه بروید و gclaude (جی کلاد) را اجرا کنید. در ویندوز این کار را در یک پنجره تازه PowerShell انجام دهید که بعد از تمام شدن نصب باز کرده‌اید. حالا کلاد با مدل‌های Opus و Sonnet آماده کار است. در VS Code هم همین دستور را در ترمینال خود VS Code اجرا کنید.

استفاده در Claude Desktop با کلید اپ

Claude Desktop و اپ‌های دیگری که با قالب API شرکت Anthropic کار می‌کنند، به جای نصب بالا با یک کلید اپ به بسته شما وصل می‌شوند.

ساختن کلید اپ

  1. وارد داشبورد شوید و به زبانه «API و اپ‌ها» بروید.
  2. روی «کلید اپ جدید» بزنید و یک نام برایش بگذارید، مثلا «لپ‌تاپ».
  3. کلید (که با sk-proxy-p- شروع می‌شود) فقط یک بار نشان داده می‌شود؛ همان موقع آن را کپی کنید و جایی امن نگه دارید.

تنظیم Claude Desktop

به Claude Desktop نسخه 1.2581.0 یا جدیدتر نیاز دارید.

  1. از منو Help → Troubleshooting → Enable Developer Mode را بزنید.
  2. بعد Developer → Configure Third-Party Inference → Gateway را باز کنید.
  3. در Base URL آدرس https://claude.rahkar.pro و در API key کلید اپ خود را بگذارید.

اپ‌های دیگر هم همین آدرس پایه و کلید را می‌گیرند.

  • کلید فقط تا وقتی بسته فعال دارید کار می‌کند و مصرفش از همان بسته کم می‌شود.
  • تا ۲۰ کلید می‌توانید بسازید؛ مصرف هر کلید را در همان زبانه ببینید و کلیدی را که دیگر لازم ندارید باطل کنید.
  • جستجوی وب، fast mode و context یک میلیون توکنی با کلید اپ کار نمی‌کند.

چند نکته

  • مصرف بسته و زمان باقی‌مانده را در داشبورد ببینید.
  • برای وصل کردن کامپیوتر دوم، همین دستور را روی آن هم اجرا کنید.
  • اگر مشکلی پیش آمد، از دکمه پشتیبانی پایین صفحه در تلگرام یا واتس‌اپ بپرسید.

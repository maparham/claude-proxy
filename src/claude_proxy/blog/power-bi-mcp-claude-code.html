اگر با Power BI کار می‌کنید، می‌دانید بیشتر وقت صرف چه می‌شود: نوشتن Measureهای DAX، نام‌گذاری ستون‌ها، درست کردن رابطه‌ها و پیدا کردن اینکه چرا یک عدد درست درنمی‌آید. مایکروسافت برای Power BI یک سرور MCP رسمی ساخته که کلاد (Claude Code) با آن مستقیم به مدل داده شما وصل می‌شود: جدول‌ها و رابطه‌ها را می‌خواند، کوئری DAX اجرا می‌کند و نتیجه را می‌بیند، و با اجازه شما Measure و ستون و رابطه می‌سازد.

اسم فعلی این سرور Power BI Authoring MCP است (قبلاً Power BI Modeling MCP بود و بسته‌اش هنوز همان نام قدیمی را دارد). نسخه ۱ آن منتشر شده و رایگان است.

پیش‌نیازها

  • ویندوز و Power BI Desktop. Power BI Desktop فقط روی ویندوز اجرا می‌شود؛ روی مک باید از ماشین مجازی ویندوز استفاده کنید.
  • Node.js نسخه ۲۲ یا بالاتر، چون سرور با npx اجرا می‌شود. اگر نصب نیست، در PowerShell: 
    winget install --id OpenJS.NodeJS.LTS --source winget
  • کلاد نصب و وصل باشد؛ اگر هنوز نه، راهنمای نصب کلاد را ببینید.
  • اجازه نوشتن (Write) روی مدلی که می‌خواهید تغییرش بدهید.

نصب

  1. فایل گزارش‌تان را در Power BI Desktop باز کنید و باز نگه دارید.
  2. اول سرور را فقط‌خواندنی اضافه کنید تا اتصال را بی‌خطر امتحان کنید. در PowerShell: 
    gclaude mcp add --transport stdio --scope user powerbi-modeling-mcp -- npx -y @microsoft/powerbi-modeling-mcp@latest --start --accepteula --readonly
    با --accepteula شرایط استفاده مایکروسافت را می‌پذیرید؛ بدون آن، همه ابزارهای سرور خطا می‌دهند. با --scope user در همه پوشه‌ها در دسترس است.
  3. gclaude (جی کلاد) را اجرا کنید و بگویید (نام فایل را همان‌طور که در نوار عنوان Power BI Desktop آمده بنویسید، بدون .pbix): 
    Connect to 'Sales' in Power BI Desktop
  4. برای آزمایش بپرسید: «جدول‌ها و تعداد ردیف‌هایشان را فهرست کن» یا «رابطه‌های مدل را نشانم بده».

اجازه نوشتن

وقتی اتصال درست بود، از کلاد خارج شوید و سرور را بدون --readonly دوباره اضافه کنید:

gclaude mcp remove --scope user powerbi-modeling-mcp
gclaude mcp add --transport stdio --scope user powerbi-modeling-mcp -- npx -y @microsoft/powerbi-modeling-mcp@latest --start --accepteula

از این به بعد کلاد پیش از اولین تغییر در هر مدل از شما تأیید می‌گیرد. آن پیام را با دقت بخوانید.

مدل‌های منتشرشده در Power BI Service

همین سرور به مدل‌های داخل یک Workspace در Fabric هم وصل می‌شود:

Connect to semantic model 'Sales' in Fabric Workspace 'Finance'

مایکروسافت برای فقط پرسیدن سؤال از مدل‌های منتشرشده یک سرور اینترنتی هم دارد (https://api.fabric.microsoft.com/v1/mcp/powerbi) که نصب نمی‌خواهد و روی مک هم کار می‌کند، ولی مدیر Power BI سازمان باید گزینه Users can use the Power BI Model Context Protocol server endpoint را در تنظیمات Tenant فعال کرده باشد.

این سرور روی کامپیوتر خودتان اجرا می‌شود و برای مدل‌های اینترنتی مستقیم به سرورهای مایکروسافت وصل می‌شود، نه از راه درگاه کلاد. ولی نام جدول‌ها و ستون‌ها، DAX و نتیجه کوئری‌ها برای کلاد فرستاده می‌شود؛ روی داده‌ای که نباید از سازمان بیرون برود کار نکنید.

با کلاد و Power BI چه کارهایی می‌شود کرد؟

  • نوشتن Measure: «یک Measure برای فروش سال قبل و درصد رشد نسبت به سال قبل بساز و در پوشه Time Intelligence بگذار.» کلاد آن را می‌سازد، با یک کوئری DAX امتحانش می‌کند و عدد را نشان‌تان می‌دهد.
  • پیدا کردن خطا: «چرا جمع فروش در این Measure با جدول اصلی نمی‌خواند؟» کلاد Measure، رابطه‌ها و فیلترها را می‌خواند و با کوئری‌های کوچک ریشه مشکل را پیدا می‌کند.
  • مرتب کردن مدل: «برای همه Measureهای جدول Sales توضیح (Description) بنویس، ستون‌های کلید را مخفی کن و نام‌ها را یکدست کن.»
  • جدول تاریخ و رابطه‌ها: «یک جدول تاریخ با سال، فصل و ماه بساز و به ستون‌های تاریخ جدول‌های فروش وصلش کن.»
  • امنیت سطری (RLS): «یک نقش بساز که هر مدیر منطقه فقط فروش منطقه خودش را ببیند.»
  • مستندسازی: «از کل مدل یک سند فارسی بنویس: جدول‌ها، رابطه‌ها و توضیح هر Measure.»

ساختن صفحه گزارش

سرور MCP فقط با مدل داده کار می‌کند، نه با صفحه‌ها و نمودارها. برای ساختن صفحه گزارش، مایکروسافت افزونه‌ای (plugin) برای کلاد منتشر کرده که روی پروژه‌های PBIP کار می‌کند: فایل را در Power BI Desktop با File، Save as و نوع Power BI Project (*.pbip) ذخیره کنید و بعد:

npm install -g @microsoft/powerbi-report-authoring-cli@latest @microsoft/powerbi-desktop-bridge-cli@latest

و داخل کلاد:

/plugin marketplace add microsoft/skills-for-fabric
/plugin install powerbi-authoring@fabric-collection

کلاد را دوباره باز کنید و مثلاً بگویید: «یک صفحه بساز با نمودار خطی فروش ماهانه و یک کارت برای جمع فروش.» این افزونه سرور MCP خودش را بدون --readonly تعریف می‌کند؛ با gclaude mcp list ببینید کدام فعال است.

چند نکته

  • پیش از اجازه نوشتن، از فایل نسخه پشتیبان بگیرید. پروژه PBIP را در Git بگذارید تا هر تغییر کلاد قابل برگشت باشد.
  • پیش از هر درخواست، فایل را در Power BI Desktop ذخیره کنید و هم‌زمان با کلاد در Desktop تغییر ندهید، وگرنه یکی از دو تغییر از دست می‌رود.
  • دقیق بخواهید: «برای Measureهای جدول Sales پوشه بساز» بهتر از «مدل را مرتب کن» جواب می‌دهد.
  • اگر کلاد گفت مجوز (EULA) پذیرفته نشده، نگذارید با PowerShell دورش بزند؛ --accepteula را به دستور نصب اضافه کنید.

کدام بسته برای کدام کار

ابزارهای این سرور زیادند و کلاد برای هر کار ساختار مدل را می‌خواند، پس مصرف توکن از یک گفت‌وگوی ساده بیشتر است. برای چند Measure و رفع یک خطا بسته اقتصادی کافی است؛ برای ساختن مدل و گزارش کامل، بسته استاندارد.

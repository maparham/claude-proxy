اگر با Unreal Engine بازی یا صحنه سه‌بعدی می‌سازید، حالا لازم نیست هر کار تکراری را با کلیک در ادیتور انجام دهید. اپیک گیمز (Epic Games) از نسخه 5.9 یک افزونه به اسم Unreal MCP در خود ادیتور گذاشته که یک سرور MCP روی کامپیوتر شما اجرا می‌کند. کلاد (Claude Code) با آن مستقیم به ادیتور باز وصل می‌شود: اکتورها را می‌بیند و می‌سازد، بلوپرینت، متریال، Niagara، PCG و Sequencer را ویرایش می‌کند، فایل وارد می‌کند و تست و پروفایل اجرا می‌کند.

این افزونه هنوز آزمایشی (Experimental) است؛ یعنی ابزارها و تنظیماتش ممکن است در نسخه‌های بعد عوض شوند.

پیش‌نیازها

  • Unreal Engine 5.9 یا بالاتر، روی ویندوز، مک یا لینوکس.
  • کلاد نصب و وصل باشد؛ اگر هنوز نه، راهنمای نصب کلاد را ببینید.
  • پروژه را در Git یا Perforce نگه دارید تا هر تغییر کلاد قابل برگشت باشد.

نصب

  1. پروژه را در ادیتور باز کنید و از منوی Edit، Plugins مطمئن شوید Unreal MCP تیک دارد (به طور پیش‌فرض روشن است).
  2. همان‌جا All Toolsets را هم روشن کنید تا همه ابزارها بارگذاری شوند، و ادیتور را یک بار ببندید و باز کنید.
  3. سرور خودش با باز شدن ادیتور روی http://127.0.0.1:8000/mcp روشن می‌شود. حالا در ترمینال (در ویندوز در PowerShell) آن را به کلاد اضافه کنید: 
    gclaude mcp add --scope user --transport http unreal-mcp http://127.0.0.1:8000/mcp
    با --scope user در همه پوشه‌ها در دسترس است.
  4. اول ادیتور را باز کنید، بعد در پوشه پروژه gclaude (جی کلاد) را اجرا کنید و /mcp را بزنید تا ببینید unreal-mcp وصل شده باشد.
  5. برای آزمایش، چند اکتور را در صحنه انتخاب کنید و بپرسید: «چه اکتورهایی انتخاب شده‌اند؟»

ساختن تنظیمات از داخل ادیتور

اگر بخواهید اتصال فقط برای همین پروژه باشد، در Edit، Editor Preferences، بخش Model Context Protocol، کلاینت را روی Claude Code بگذارید و Generate Client Config را بزنید (یا در کنسول ادیتور ModelContextProtocol.GenerateClientConfig ClaudeCode). ادیتور یک فایل .mcp.json در پوشه پروژه می‌سازد و gclaude بار اول که در آن پوشه اجرا شود اجازه استفاده از آن را می‌پرسد. اگر انجین را خودتان از سورس ساخته‌اید، فایل در پوشه انجین ساخته می‌شود و باید آن را به پوشه پروژه کپی کنید.

کلاد داخل ادیتور

با افزونه Terminal ادیتور می‌توانید کلاد را بدون بیرون رفتن از Unreal اجرا کنید. در تنظیمات آن، این سه دستور را به ترتیب به عنوان دستورهای شروع بگذارید (در ویندوز set TERM=xterm-256color و cd /d):

export TERM=xterm-256color
cd "مسیر پوشه پروژه"
gclaude

بدون خط اول، خروجی کلاد پر از کاراکترهای عجیب می‌شود.

سرور روی کامپیوتر خودتان اجرا می‌شود و فقط از همان کامپیوتر قابل دسترسی است. ولی نام اکتورها و فایل‌ها، کد بلوپرینت‌ها و تصویرهایی که ابزارها برمی‌گردانند برای کلاد فرستاده می‌شود؛ روی پروژه‌ای که قرارداد محرمانگی دارد بدون اجازه کار نکنید.

با کلاد و Unreal چه کارهایی می‌شود کرد؟

  • چیدن صحنه: «دور تا دور این زمین ۴۰ درخت با فاصله و چرخش تصادفی بچین و همه را در پوشه Trees در Outliner بگذار.»
  • بلوپرینت: «یک بلوپرینت برای دری بساز که وقتی بازیکن نزدیک شد باز شود و صدا پخش کند.» کلاد گره‌ها را می‌سازد و به هم وصل می‌کند.
  • متریال و جلوه‌ها: «یک متریال آب با موج و شفافیت بساز» یا «جرقه‌های این افکت Niagara را کمتر و نارنجی‌تر کن.»
  • رابط کاربری: «یک Widget Blueprint برای منوی اصلی با سه دکمه شروع، تنظیمات و خروج بساز.»
  • وارد کردن فایل: «همه مدل‌های پوشه Downloads/props را وارد کن، برایشان متریال بساز و نام‌ها را با قاعده پروژه یکی کن.»
  • پیدا کردن کندی: «یک پروفایل از این سطح بگیر و بگو چه چیزی فریم‌ریت را پایین آورده.»
  • تست: «تست‌های خودکار پروژه را اجرا کن و هر کدام شکست خورد علتش را پیدا کن.»

چند نکته

  • کارهای بزرگ را تکه‌تکه بخواهید. ابزارها یکی‌یکی روی رشته اصلی ادیتور اجرا می‌شوند و کلاد اگر جواب یک ابزار بیش از حدود دو دقیقه طول بکشد، منتظر نمی‌ماند.
  • پیش از هر درخواست بزرگ، کار را ذخیره کنید و هم‌زمان با کلاد همان بلوپرینت یا سطح را ویرایش نکنید.
  • اگر دو نسخه ادیتور باز دارید، به هر کدام پورت جدا بدهید (مثلاً اجرای ادیتور با -ModelContextProtocolPort=8001) و هر کدام را با یک نام جدا اضافه کنید: 
    gclaude mcp add --scope user --transport http unreal-mcp-2 http://127.0.0.1:8001/mcp
  • اگر کلاد وصل نشد، در کنسول ادیتور ModelContextProtocol.StartServer را بزنید و در Output Log دنبال LogModelContextProtocol بگردید.
  • سرور رمز عبور ندارد. آن را به شبکه باز نکنید و نشانی آن را عوض نکنید که از کامپیوترهای دیگر هم در دسترس باشد.

کدام بسته برای کدام کار

کلاد برای هر کار اول صحنه و دارایی‌ها را می‌خواند و گاهی تصویر از ادیتور می‌گیرد، پس مصرف توکن از یک گفت‌وگوی ساده بیشتر است. برای چند کار کوچک در صحنه بسته اقتصادی کافی است؛ برای ساختن سیستم‌های بازی و کار روزانه روی پروژه، بسته استاندارد.

چیدن یک صحنه یا ساختن چند متریال
ساختن بلوپرینت‌ها و منوهای یک بخش از بازی
کار روزانه روی یک پروژه بازی، از صحنه تا تست و پروفایل
